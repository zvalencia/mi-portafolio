
# Mi Portafolio - Aprendiz ADSO

## Descripción

Este repositorio contiene mi portafolio personal como aprendiz de Análisis y Desarrollo de Software del SENA. Su propósito es presentar mi perfil, mostrar ejercicios académicos de desarrollo web y compartir los conocimientos que voy adquiriendo durante mi formación.

## Tecnologías utilizadas

Para la elaboración de este portafolio se utilizan las siguientes tecnologías:

- HTML para organizar el contenido de la página.
- CSS para dar estilo y mejorar la presentación visual.
- JavaScript para incorporar funciones a la página.
- Git para llevar el historial de cambios.
- GitHub para publicar y compartir el proyecto.

## Cómo ver el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre el archivo `index.html` en tu navegador.

Puedes consultar la plataforma [GitHub](https://github.com/) para conocer más sobre el desarrollo de software.
