# Etiquetas (labels) del repositorio

Crea estas etiquetas en tu repositorio: **Issues → Labels → New label**.
GitHub ya trae algunas por defecto (`bug`, `documentation`, `enhancement`...).
Puedes conservar `bug` y crear las demás.

| Etiqueta     | Color     | ¿Para qué se usa?                                   |
|--------------|-----------|-----------------------------------------------------|
| `historia`   | `#8250DF` | Issue que describe una historia de usuario           |
| `bug`        | `#D73A4A` | Algo que debería funcionar y no funciona             |
| `frontend`   | `#0969DA` | Cambios en HTML o CSS                                |
| `docs`       | `#0E8A16` | Cambios en README u otra documentación               |
| `prioridad-alta` | `#B60205` | Debe hacerse primero                              |
| `prioridad-baja` | `#FBCA04` | Puede esperar                                     |
